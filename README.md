# OfferForge AI 🚀

OfferForge AI is a full-stack AI-powered career preparation platform that analyzes resumes against job descriptions to generate job match scores, identify skill gaps, generate interview questions, and provide resume improvement suggestions using Gemini AI.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Gemini AI
- Puppeteer
- Multer
- SCSS

## Features

- JWT Authentication
- Resume Upload
- Resume Parsing
- Job Description Matching
- Job Match Score
- Skill Gap Detection
- AI Interview Questions
- Resume Suggestions
- Preparation Roadmap
- PDF Generation
